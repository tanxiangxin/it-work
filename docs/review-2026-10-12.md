## 已修复问题

- **自定义模型网络边界**：用户填写的模型地址原本可以访问本机、内网和云元数据服务。现在拒绝非公网地址、混合公私网 DNS 结果及重定向，连接固定到已校验的公网 IP；保留原域名 Host、TLS SNI 和证书验证，禁用自定义请求的环境代理。服务器配置的内部向量服务保持可用。
- **地址校验**：无效端口、超范围端口和地址内部空白原本可能进入模型请求，现返回配置错误。
- **模型异常输出**：OpenAI `choices` 内出现 null、字符串或缺失 message 时原本可能抛出未处理异常，现统一返回 `MODEL_OUTPUT`。
- **日期边界**：通知筛选结束日期为 `9999-12-31` 时，计算下一天发生溢出。现使用该日期全天的最大时刻作为包含边界。
- **题型约束**：只校验总共十题不足以兑现界面的五道判断题、五道简答题。现在服务端校验比例，不合格结果不保存。
- **跨课程结果**：课程 A 的后台结果延迟返回时，可能覆盖已切换到课程 B 的结果，并用 B 的 ID 提交 A 的练习。现在只发布当前课程的结果，返回数据明确包含 `course_id`，练习使用所属课程 ID。
- **草稿恢复**：JSON 可解析但类型损坏的本机草稿可能造成输入或作答页面异常。恢复前校验保存结构、值类型及答案数量。
- **事务释放**：工单摘要读取自定义模型配置后重新开启了数据库读事务。现在先读取配置，再释放事务，模型等待期间不占用该事务。
- **来源提示**：联网回答统一明确标为来自联网搜索，历史模型上下文也保留该来源区分。
- **回归用例**：更新后台任务的 HTTP 202/轮询契约、具名选择器和新增任务表的外键清理顺序；工单流程使用唯一标题，支持重复执行。测试报告目录从 Git 与前端构建上下文排除。
