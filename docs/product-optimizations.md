# 搜索筛选、草稿恢复与后台学习任务

## 搜索与筛选

- 校园通知按标题搜索，可叠加类别、收藏和发布起止日期。起止日期均按北京时间，包括结束日期全天；草稿没有发布时间，因此不出现在按发布时间筛选的结果中。
- 个人待办按标题搜索，可叠加完成状态、今天到期、未来7天到期和已逾期。到期筛选只显示未完成事项。未来7天从当前时刻起计算，今天到期包括当天已经过期的事项。
- 默认优先展示未完成且尚未过期的事项，按截止时间从近到远排列，已完成记录最后显示。筛选改变时回到第一页，支持一键重置。
- 搜索在服务端分页前执行；百分号和下划线按普通字符搜索，不作为SQL通配符。

## 本机草稿

- 通知新增/编辑、待办新增/编辑、从通知添加的待办，在输入变化和AI提取后立即保存本机草稿；再次打开表单提示“恢复草稿”。最终保存成功后清除草稿。
- 练习答案按账号、课程和练习记录保存，学习问题/主题按账号、课程和任务类型保存。答案只有评分成功后才清理；失败时保留。
- 草稿保存在当前浏览器localStorage，按账号隔离，30天后过期，不跨浏览器或设备同步。可主动清除；浏览器存储不可用时显示提示。退出登录保留该账号草稿，其他账号页面不会恢复它。
- 最近选择的课程在本机保留，刷新后优先返回该课程。

## 后台学习任务

- 提纲生成、练习生成和练习评分返回202，交给Celery Worker处理。资料问答保留原有即时请求流程。
- “后台学习任务”卡片显示最近5个任务，状态为排队中、处理中、已完成、失败。后台每门课程限制一个活动任务，避免并发重复操作。
- 刷新或切换页面后仍可查看进度。完成或失败时发送站内消息，点击消息直接打开对应课程结果或错误。成功结果仍保存在原学习记录中。
- 失败任务可重试，会创建新任务并保留原错误；评分重试沿用当时提交的答案，也可修改答案后重新提交。
- 数据库记录先于消息队列发布。调度器每30秒补发排队任务；处理中超过30分钟的任务标记失败，用户可重试。租约失效的旧Worker不能发布结果。结果保存、任务完成及消息通知在同一数据库事务提交。
- 删除课程会清理该课程的学习任务和关联消息，进行中的任务无法发布结果。任务、答案及结果只允许课程所有者访问，管理员不能查看他人的个人学习任务。

## 接口与迁移

- `GET /announcements`新增`q`、`published_from`、`published_to`。
- `GET /todos`新增`q`、`due=today|upcoming|overdue`。
- `POST/GET /courses/{id}/study-jobs`创建任务/查看最近任务。
- `POST /courses/{id}/study/{run_id}/grade-jobs`提交后台评分。
- `GET /study-jobs/{id}`读取本人任务及成功结果。
- `POST /study-jobs/{id}/retry`重试失败任务。
- 迁移`0012_study_jobs`新增任务表和消息目标字段，保留已有通知、待办、课程和学习记录。原同步学习接口保留兼容。
