# 湖南工业大学公开服务知识库

## 内容与出处

采集核验日期为2026-10-10。首批18个主题来自湖南工业大学官网、教务处、学生工作部、现代教育技术中心、就业信息网和图书馆公开页面。知识文档是人工核验后的摘要，不是学校授权发布的办事文件，也未连接学校个人数据或审批系统。

领域包括教学办事与科室职责、当学期教学通知入口、毕业证明书历史资料、公共机房预约、校园卡、水电充值及退费、网络与身份认证、邮箱、故障报修、学生事务、资助、勤工助学、宿舍服务、心理服务导航、图书馆与就业实习。完整内容和来源映射见 [资料清单](../samples/hut/manifest.json)。每个Markdown文档保留学校、领域、原文日期、核验日期、原文链接和具体限制，长度控制在950字符内，使一段检索内容能同时保留出处与时间背景。

仅收录公开服务信息。未导入奖助公示中的学生个人名单、身份证、手机号、成绩、银行卡或咨询记录。官网公开的业务电话号码按页面展示收录，不代表已验证接通、接待时间或全天服务。搜索中的湖南工学院、湖南科技大学、湖南工商大学等相近校名以及未验证的第三方软件下载入口均未纳入。

- 2026年9月故障报修通知、2026年秋季勤工助学通知已核验文字正文。岗位明细PNG中的时间、名额、薪酬没有转写。

- 2018年毕业证明书表格明确标为历史资料，办理时必须核实当前要求。2025年IT Q&A的APP菜单可能调整。
- 图书馆门户可访问，但动态栏目主要从官方页面的搜索索引确认；未核验当日开放时间、借阅数量或期限。
- 2026版现教中心服务指南的附件下载未取得可解析PDF，因此没有导入其未验证正文。
- 该批资料不提供2026年完整学生手册、实时课表、成绩、余额、全部收费标准、校历、医疗建议或当前奖助申请金额。新增这些内容时应继续核验官方原文。

## 导入与更新

`samples/hut/manifest.json` 是本批资料的编辑来源，`scripts/import_hut_knowledge.py` 从清单生成Markdown，通过管理员登录后的正式上传接口导入，等待Worker解析、BGE-M3向量化及版本发布。重复导入利用后端文件哈希与索引标识复用已有版本；修改摘要后生成新版本，失败时旧版本仍可用。导入报告保存文件哈希、文档/版本/任务编号、状态和来源。

```powershell
# 只生成和检查文档，无需账号
python scripts/import_hut_knowledge.py --prepare-only
# 设置已有管理员账号的实际密码；不要提交到Git
$env:EVAL_ADMIN_PASSWORD = '<管理员实际密码>'
python scripts/import_hut_knowledge.py --hide-demo
Remove-Item Env:EVAL_ADMIN_PASSWORD
```

`--hide-demo` 仅将最初三个模拟指南 accounts.md、campus-network.md、vpn-809.md 改为管理员可见，不删除文件或历史；权限变更会撤销学生历史引用的访问。管理员仍可用于工程演示，但应避免将其作为真实学校政策引用。若恢复模拟演示，可在知识库管理界面改回公开。原有检索对比报告使用旧演示语料，不能直接和当前湖工大语料混作同一基准。

后续维护建议：每学期核验服务联系方式、学工和教务通知；动态截止日、费用、岗位是否开放先查当前原文，来源有变化时修改清单再导入。当前没有自动抓取或定时更新任务。
