# 消息中心

主界面右上角“消息”按钮展示未读数量，打开后分页查看系统消息，可查看关联工单或全部标为已读。

- 新增工单通知其他管理员。
- 回复和状态变化通知工单提交人及其他管理员；操作者本人不接收自己的通知。
- 消息与工单操作在同一数据库事务提交，重复提交工单不会重复通知。消息归属由登录身份决定，不能读取或修改其他用户的消息。
- 在线每 5 秒轮询新消息，弹窗可直接查看工单。首次进入页面只同步未读数量，历史消息不会集中弹窗；断线后自动重试并补取消息。每批最多 100 条，连续补取；超过 3 条的提醒合并提示。
- 点击查看工单标记该消息已读；关闭弹窗不标记已读。离线消息和已读记录持久化，刷新、重新登录后仍可查看。
- 使用站内提醒，无需浏览器桌面通知权限。新表由 Alembic `0004_notifications` 创建；历史工单不会自动回填通知。

验证：`docker compose --profile test run --build --rm tests`；前端 `pnpm exec playwright test notifications.spec.ts login.spec.ts`。浏览器消息测试通过隔离的测试工单触发事件，结束后清理该测试工单及消息，不调用模型。
